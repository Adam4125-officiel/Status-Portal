A real Discord bot connection - separate from the simple Discord webhook notifications in Settings. It can update its own presence/status and/or respond to a /{{ command_name }} slash command in any channel it can see by posting a status summary, then keep editing that same message on a timer instead of spamming new ones.

To enable this feature:

  1. Create an application + bot at the Discord Developer Portal.
  2. Invite it to your server with permission to view channels and send messages (no privileged intents needed - this uses a slash command, not a text command).
  3. Install the optional dependency: pip install discord.py
  4. Set PORTAL_DISCORD_BOT_TOKEN in .env to the bot's token.
  5. Optional but recommended for a single-server bot: set PORTAL_DISCORD_BOT_GUILD_ID to your server's ID (enable Developer Mode in Discord, then right-click your server icon → Copy Server ID) so the slash command appears instantly instead of taking up to an hour to register globally.
  6. Restart the app.

Gates both /{{ command_name }} (posts a status message once, then keeps editing that same message on a timer instead of posting new ones - including across an app restart) and /snapshot (a short one-shot reply: which services are down, if any, and whether any incident or maintenance is currently open - not tracked/edited afterward).
Shows up as /{{ command_name }} in Discord. Lowercase letters/numbers/-/_ only. Changing this needs an app restart to re-register with Discord. "snapshot" is reserved for the separate /snapshot command below and can't be used here.
Comma or newline separated. Applies to both /{{ command_name }} and /snapshot. Leave blank and anyone in the server can use these commands - set this if you want to restrict who can trigger them (e.g. to avoid spam). Enable Developer Mode in Discord's settings, then right-click a user → Copy User ID.
Comma or newline separated server (guild) IDs. Leave blank and the bot stays in any server it's invited to. If set, the bot automatically leaves any server whose ID isn't on this list - checked the moment it's invited, and again every time it (re)connects, so removing a server later still takes effect. Enable Developer Mode in Discord's settings, then right-click a server icon → Copy Server ID.
