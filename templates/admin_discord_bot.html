Discord Bot

A real Discord bot connection - separate from the simple Discord webhook notifications in Settings. It can update its own presence/status and/or respond to a command word in any channel it can see by posting a status summary, then keep editing that same message on a timer instead of spamming new ones.

To enable this feature:

  1. Create an application + bot at the Discord Developer Portal.
  2. Under Bot settings, enable the Message Content Intent - without it the bot cannot read the command word below.
  3. Invite it to your server with permission to view channels and send/edit messages.
  4. Install the optional dependency: pip install discord.py
  5. Set PORTAL_DISCORD_BOT_TOKEN in .env to the bot's token, then restart the app.
