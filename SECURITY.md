# Security policy

## Supported versions

Only the latest stable release is supported. Security fixes land on the default
branch and are released as a new version; older versions are not patched. The
current version is in the `VERSION` file and on the Releases page.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub's private vulnerability reporting: open the
repository's **Security** tab and choose **Report a vulnerability**. Include what
you found, how to reproduce it, and the version you tested. Reports stay visible
only to the maintainer and to you until a fix is published.

This project does not publish a contact email for security reports.
